
# Survey Feedback Analyzer

## Description
A Python-based project designed to collect, clean, and analyze customer survey feedback using Python programming concepts.

## Objectives
- Store feedback using a dictionary of lists.
- Collect and append additional customer feedback.
- Perform text cleaning and preprocessing.
- Analyze feedback using keyword counting.
- Calculate average customer ratings.
- Identify the longest feedback comment.
- Extract unique words from feedback entries.
- Sort feedback based on ratings.

## Tools & Technologies
- Python
- Jupyter Notebook

## Key Features
- **Data Collection:** Collect customer names, written feedback, and ratings.
- **Data Storage:** Store feedback in a dictionary of lists.
- **Text Cleaning:** Remove punctuation, extra spaces, and convert text into lowercase.
- **Word Count Analysis:** Count feedback entries containing specific keywords.
- **Rating Analysis:** Calculate average customer ratings.
- **Longest Feedback:** Identify the comment with the highest word count.
- **Unique Words:** Extract distinct words from all feedback entries.
- **Sorting:** Arrange feedback by rating in descending order.

## Python Concepts Used
- Dictionary and Lists
- For Loops
- Conditional Statements
- User-Defined Functions
- String Methods
- Lambda Functions
- Sets
- `max()` and `len()`
- `zip()` and `sorted()`

## Key Learnings
- Managing structured data using dictionaries and lists.
- Applying text-cleaning techniques.
- Working with functions and loops.
- Performing keyword-based text analysis.
- Extracting insights from customer feedback.
- Analyzing numerical ratings.

## Conclusion
This project demonstrates the use of Python for survey feedback processing and basic text analysis. It extracts meaningful insights through data cleaning, keyword analysis, and rating summaries.
